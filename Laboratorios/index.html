Preguntas

¿Cuál es la diferencia entre Internet y la World Wide Web?

Internet es una red global de redes interconectadas que permite la comunicacion entre milllones de dispositivos mediante protocolos como TCP/IP. Es la infraestructura física y lógica que conecta computadoras en todo el mundo. La World Wide Web es un servicio que funciona sobre Internet y permite acceder a documentos y recursos mediante navegadores web usando el protocolo HTTP o HTTPS. La Web es solo uno de los servicios que utiliza Internet, junto con el correo electrónico, FTP, entre otros.

¿Cuáles son las partes de un URL?

Un URL (Uniform Resource Locator) es la dirección que permite localizar un recurso en la Web. Está compuesto por varias partes: el protocolo, que indica cómo se accederá al recurso (por ejemplo, https); el dominio, que identifica el servidor donde se encuentra alojado el recurso; el puerto, que es opcional y especifica el servicio; la ruta, que señala la ubicación específica del archivo dentro del servidor; los parámetros, que envían información adicional; y el fragmento, que dirige a una sección específica dentro del documento.

¿Cuál es el propósito de los métodos HTTP: GET, HEAD, POST, PUT, PATCH, DELETE?

Los métodos HTTP definen el tipo de acción que se desea realizar sobre un recurso en un servidor. El método GET se utiliza para solicitar información; HEAD obtiene únicamente los encabezados de la respuesta; POST se emplea para enviar datos al servidor, generalmente para crear un recurso; PUT reemplaza completamente un recurso existente; PATCH modifica parcialmente un recurso; y DELETE elimina un recurso del servidor. Estos métodos permiten que la comunicación entre cliente y servidor sea estructurada y organizada.

¿Qué método HTTP se debe utilizar al enviar un formulario HTML, por ejemplo cuando ingresas tu usuario y contraseña en algún sitio? ¿Por qué?

Cuando se envía un formulario que contiene usuario y contraseña, se debe utilizar el método POST. Esto se debe a que los datos se envían en el cuerpo de la solicitud y no aparecen visibles en la URL, lo que reduce la exposición de información sensible. Además, los datos enviados por POST no quedan almacenados directamente en el historial del navegador, lo que ofrece mayor seguridad en comparación con el método GET.

¿Qué método HTTP se utiliza cuando a través de un navegador web se accede a una página a través de un URL?

Cuando un usuario escribe una dirección en el navegador y accede a una página web, el navegador utiliza el método GET para solicitar el recurso al servidor. Este método es el estándar para recuperar información sin modificar los datos almacenados en el servidor.

Un servidor web devuelve una respuesta HTTP con código 200. ¿Qué significa esto? ¿Ocurrió algún error?

El código HTTP 200 indica que la solicitud realizada por el cliente fue procesada correctamente por el servidor y que el recurso solicitado fue entregado exitosamente. Este código no representa ningún error, sino que confirma que la comunicación fue exitosa.

¿Es responsabilidad del desarrollador corregir un sitio web si un usuario reporta que intentó acceder al sitio y se encontró con un error 404? ¿Por qué?

El error 404 indica que el recurso solicitado no fue encontrado en el servidor. Si este error se debe a un enlace interno mal configurado, a una ruta incorrecta o a un recurso eliminado sin redirección adecuada, es responsabilidad del desarrollador corregirlo. Esto es importante porque los errores 404 afectan la experiencia del usuario y pueden perjudicar la credibilidad del sitio web.

¿Es responsabilidad del desarrollador corregir un sitio web si un usuario reporta que intentó acceder al sitio y se encontró con un error 500? ¿Por qué?

El error 500 indica un problema interno en el servidor, generalmente relacionado con errores en el código del backend, configuraciones incorrectas o fallos en la base de datos. En la mayoría de los casos, sí es responsabilidad del desarrollador o del administrador del sistema corregirlo, ya que se trata de un problema técnico que impide el correcto funcionamiento del sitio.

¿Qué significa que un atributo HTML5 esté depreciado o desaprobado (deprecated)? Menciona algunos elementos de HTML 4 que en HTML5 estén desaprobados.

Cuando un elemento o atributo HTML está marcado como deprecated significa que ya no se recomienda su uso en versiones actuales del estándar, debido a que ha sido reemplazado por alternativas más modernas y eficientes. En HTML5, varias etiquetas de HTML4 quedaron desaprobadas, como <font>, <center>, <big>, <strike> y <frame>. En lugar de estas etiquetas, se recomienda utilizar CSS para controlar la presentación y el diseño.

¿Cuáles son las diferencias principales entre HTML 4 y HTML5?

HTML5 introduce etiquetas semánticas como header, nav, section, article y footer, que mejoran la estructura del documento. También incorpora soporte nativo para audio y video, nuevos tipos de campos en formularios y una declaración DOCTYPE simplificada, lo que facilita el desarrollo de aplicaciones web modernas.

¿Qué componentes de estructura y estilo tiene una tabla?

Una tabla en HTML se compone de los elementos table, thead, tbody, tr, th y td. La estructura organiza los datos en filas y columnas, mientras que el estilo visual se controla mediante CSS para definir bordes, colores y alineación.

¿Cuáles son los principales controles de una forma HTML5?

Los principales controles incluyen input en sus diferentes tipos como text, email, password, number y date; textarea para texto extenso; select para listas desplegables; y button para enviar datos. Estos controles permiten una mejor validación y experiencia de usuario.

¿Qué tanto soporte HTML5 tiene el navegador que utilizas?

El navegador Safari en macOS presenta un alto nivel de soporte para las características de HTML5, incluyendo multimedia, almacenamiento local y formularios avanzados. Según herramientas como html5test.com, Safari ofrece compatibilidad sólida con los estándares actuales, lo que permite desarrollar aplicaciones web modernas con buen rendimiento y compatibilidad.

Sobre el ciclo de vida y desarrollo de los sistemas de información

¿Cuál es el ciclo de vida de los sistemas de información?

El ciclo de vida de los sistemas de información describe las etapas generales por las que pasa un sistema desde su concepción hasta su retiro. Estas etapas incluyen planeación, análisis, diseño, implementación, operación y mantenimiento. Cada fase cumple una función específica para garantizar que el sistema cumpla con los objetivos organizacionales y se mantenga funcional a lo largo del tiempo.

¿Cuál es el ciclo de desarrollo de sistemas de información?

El ciclo de desarrollo de sistemas, también conocido como SDLC, se enfoca específicamente en el proceso técnico de creación del software. Incluye la recolección de requisitos, análisis, diseño, programación, pruebas, implementación y mantenimiento. Este ciclo permite estructurar el desarrollo del sistema de manera organizada, asegurando calidad, eficiencia y reducción de errores.

Preguntas Laboratorio 03

Como ingeniero de software ¿cuál es tu recomendación sobre el uso de !important en un CSS?

Como ingeniero de software, mi recomendación es evitar el uso de !important en la mayoría de los casos, ya que rompe la jerarquía natural de especificidad del CSS y dificulta el mantenimiento del código. Cuando se utiliza con frecuencia, puede generar conflictos entre estilos y hacer que el diseño sea difícil de depurar y escalar. En lugar de usar !important, es preferible estructurar correctamente los selectores y aprovechar la especificidad y el orden natural del CSS. Solo debería emplearse en situaciones muy específicas y justificadas.

Si se pone una imagen de fondo en una página HTML, ¿por qué debe escogerse con cuidado?

Una imagen de fondo debe escogerse con cuidado porque influye directamente en la legibilidad del contenido y en el rendimiento del sitio web. Si la imagen tiene demasiado contraste o colores muy fuertes, puede dificultar la lectura del texto. Además, si el archivo es demasiado pesado, aumentará el tiempo de carga de la página, afectando la experiencia del usuario. Por estas razones, es importante elegir imágenes optimizadas, de tamaño adecuado y que mantengan una buena armonía visual con el contenido.

Como ingeniero de software, ¿cuál es tu recomendación al elegir las unidades de un propiedad de estilo entre %, px y pt?

Mi recomendación es priorizar el uso de unidades relativas como el porcentaje (%) cuando se busca un diseño adaptable o responsivo, ya que permiten que los elementos se ajusten al tamaño de la pantalla. Los píxeles (px) son útiles cuando se requiere precisión exacta en tamaños específicos. Por otro lado, los puntos (pt) se utilizan principalmente en contextos de impresión y no son recomendables para diseño web moderno. Elegir correctamente las unidades mejora la adaptabilidad, accesibilidad y mantenimiento del sitio.

¿Por qué el uso de una versión minimizada del CSS mejora el rendimiento del sitio?

El uso de una versión minimizada del CSS mejora el rendimiento porque reduce el tamaño del archivo eliminando espacios innecesarios, saltos de línea y comentarios. Esto disminuye la cantidad de datos que el navegador debe descargar, lo que acelera el tiempo de carga de la página. En sitios web con muchos usuarios o múltiples archivos de estilo, esta optimización puede generar una mejora significativa en la velocidad y eficiencia del sitio.

Preguntas de Fundamentos de JavaScript

¿Qué diferencias y semejanzas hay entre Java y JavaScript?

Java y JavaScript son lenguajes distintos aunque comparten algunas similitudes sintacticas. Java es un lenguaje compilado, fuertemente tipado y orientado a objetos, que se ejecuta en la maquina virtualJava (JVM). En cambio, JavaScript es un lenguaje interpretado, dinamico y multiparadigma que se ejecuta principalmente en navegadores web. Mientras Java requiere declarar tipos de datos, JavaScript utiliza tipado dinamico. Ambos comparten estructuras como ciclos y condicionales.

¿Qué métodos tiene el objeto Date?

El objeto Date permite manipular fechas y tiempos en JavaScript. Algunos de sus metodos principales son getFullYear(), getMonth(), getDate(), getHours(), getMinutes() y getSeconds(). Estos metodos permiten obtener informacion especifica de una fecha determinada.

¿Qué métodos tienen los arreglos?

Los arreglos en JavaScript poseen numerosos métodos que facilitan la manipulación de datos. Entre los más comunes se encuentran push(), que agrega un elemento al final del arreglo; pop(), que elimina el último elemento; shift(), que elimina el primer elemento; unshift(), que agrega un elemento al inicio; slice(), que devuelve una copia parcial del arreglo; splice(), que permite agregar o eliminar elementos en posiciones específicas; map(), que crea un nuevo arreglo aplicando una función a cada elemento; y filter(), que genera un arreglo con elementos que cumplen cierta condición.

¿Cómo se declara una variable con alcance local dentro de una función?

Una variable con alcance local en JavaScript se declara utilizando las palabras clave let o const dentro de una función. Estas variables solo pueden ser accedidas dentro del bloque o función donde fueron definidas. El uso de let y const mejora el control del alcance y evita problemas asociados con variables globales, promoviendo una mejor organización y seguridad del código.

¿Qué implicaciones tiene utilizar variables globales dentro de funciones?

El uso de variables globales puede generar conflictos de nombres, dificultad en el mantenimiento del código y comportamientos inesperados, ya que cualquier parte del programa puede modificarlas. Esto aumenta el riesgo de errores difíciles de detectar y afecta la modularidad del sistema. Desde una perspectiva de ingeniería de software, se recomienda limitar el uso de variables globales y preferir variables locales para mejorar la encapsulación y la seguridad del programa.
